
# Particle Life Simulation

An N-body simultion gravitational simulation based on Jeffrey Ventella's original algorithm, [Clusters](https://www.ventrella.com/Clusters/intro.html).

Currently optimized for a max of ~ 1800-2000 particles of eight different 'species'. There is room for optimzations, including spacial partitioning and parallelization. Also on the TO-DO list is a UI overhaul.
